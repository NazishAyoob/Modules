Syntax and Commenting

This page shows JavaScript syntax rules, best practices, and how to comment code for clarity.

Statements and semicolons

JavaScript uses statements separated by semicolons, though automatic semicolon insertion (ASI) exists — prefer explicit semicolons in production code for predictability.

Comments

// single-line comment
/*
   multi-line comment
*/

Naming and formatting

Use descriptive names, camelCase for variables and functions, and consistent indentation.
