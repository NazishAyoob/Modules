Lesson 19 — Values and Types (Comprehensive)

This page covers JavaScript values and types in detail: primitives, reference types, typeof behavior, coercion, and common pitfalls. Every topic includes runnable examples (inline JS) so you can explore results directly in the browser.

1. Primitive types

Primitives are immutable values and include: number, string, boolean, undefined, null, symbol, and bigint.


    

  


  

    
2. Reference types (objects)

    
Objects, arrays, and functions are reference types: variables hold references to heap values. Mutating a referenced value affects all references to it.

    

      
      

    

  


  

    
3. typeof and pitfalls

    
typeof null is an historical quirk that returns "object". Use explicit checks for null and arrays.

    

      
      

    

  


  

    
4. Coercion and comparison

    
JavaScript performs implicit type conversion in some operations. Prefer === and explicit parsing for safety.

    

      
      

    

  


  

    
5. Special numeric values

    
Watch out for NaN, Infinity, and integer precision limits. Use Number.isNaN() and Number.isFinite().

    

      
      

    

  


  

    
6. Symbols & BigInt

    
Symbol() creates unique identifiers. BigInt supports integers beyond Number.MAX_SAFE_INTEGER.

    

      
      

    

  


  

    
7. Practical checklist

    
    
      
  • Prefer let/const over var.
    • 
      
  • Use ===/!== to avoid coercion surprises.
    • 
      
  • Check arrays with Array.isArray().
    • 
      
  • Use explicit parsing: Number("123") instead of relying on +"123" everywhere.
