Math Object — Methods and Activities

The built-in Math object provides constants and functions for numeric operations.

Common methods

  • Math.abs(x)
  • Math.round(x), Math.floor(x), Math.ceil(x)
  • Math.min(...), Math.max(...)
  • Math.pow(x,y), Math.sqrt(x)
  • Math.random() (0–1)
  • Trigonometry: Math.sin, Math.cos, Math.atan2
